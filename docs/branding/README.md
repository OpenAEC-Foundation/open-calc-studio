# Open Calc Studio logo

`open-calc-studio.png` is the approved OpenAEC logo: a large amber euro sign on
an anthracite tile with rounded, transparent corners. Use this PNG for video
production and marketing artwork.

Application icons are generated from this artwork, including the browser and
in-app logo, PWA icons, Tauri desktop icons and mobile launcher icons. The SVG
files embed the approved raster artwork so the existing application URLs remain
stable; they are not separately drawn vector versions.

To regenerate the application assets, install Pillow and run from the repository:

```sh
python3 scripts/generate-app-icons.py
```
