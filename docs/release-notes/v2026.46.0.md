# Open Calc Studio 2026.46.0

Released on 11 November 2026. Product version **2026.46.0**,
Windows MSI **26.46.0**, native project format **2.4.0** (unchanged).
[Build, signing, import and UI evidence](../release-verification/2026.46.0.md)
records the completed release checks and separates them from real-host/device acceptance.

## Safer editing and calculation — #66

- Opening a project through a file association or drag-and-drop retains its
  quotation and snapshots, using the full project loader.
- Undo/redo after saving marks the document as changed again, protecting close
  and recovery. A single character typed into a selected grid cell is saved.
- Imported TRADXML, legacy CUF and Inschrijfstaat prices survive recalculation.
  RSX export includes items below nested chapters.
- Leaving the hours field without editing no longer rescales labour costs.
  Dependent spreadsheet formulas recalculate, including linked quantities.
- HSB wall labour is counted once. Changing a unit to `uur` preserves the amount
  and an explicitly entered zero norm. Quote PDFs preserve explicit zero VAT.
- **Check existing estimates with production capacity:** on rate-group labour
  lines, capacity now divides both hours and cost. For example, quantity 10 ×
  norm 1 ÷ capacity 2 × rate 64 gives 320, previously 640. This intentional fix
  can reduce existing totals. Direct labour prices and capacity 1 are unchanged.
- Snap publication waits for a published stable GitHub release. The Snap and
  updater manifest each receive a separate checksum, since they are generated
  after the installer checksum manifest.

## Navigation, currencies and mobile

- A collapsible structure tree with synchronized selection, drag-and-drop,
  context-menu moves, depth controls and optional amounts/percentages.
- Moving rows preserves other chapters' order and keeps selection on the moved
  rows. Folding safely resets a multirow selection.
- Currency is selected per estimate. Number notation follows the app language,
  with an explicit setting; existing installations retain their saved notation.
- Labour rates follow undo and price updates. Several input and paste issues
  have been corrected. Mobile spreadsheets show formula results; the statistics
  button no longer covers navigation and Done.

## IFCX interoperability — #69

- First direct reader for `openaec::cost::estimateItem`, retaining identity,
  quantity references, all model paths, source tariff, currency and rounded
  amount through native save/reopen.
- Existing Calc IFCX readers and exports keep their format. External IFCX
  imports are not downloaded automatically. Supply resolved quantity nodes in
  the same document; unsupported or inconsistent input fails explicitly.
- The Explorer reference probe imported 2,703 posts, EUR 397,443.12 direct costs.
  Maximum line delta after save/reopen and recalculation: 2.28e-13 EUR. This
  proves field mapping, not the accuracy of the example model or its rates.
- [Contract and reproduction](../ifcx-interoperability.md).

## Hosted workspaces and distribution — #73, #35, #68

- Platform bundles expose `mcp-tools.json`; desktop MCP offers the same nine
  `calc_*` tools. Startup is compatible with a strict CSP without inline scripts.
- Host conflict copies, refused saves and historical read-only versions have
  explicit handling. Unsupported second-screen controls are hidden in opaque
  frames. Web builds no longer start native file association hooks.
- Store metadata is synchronized from the released Snap, with a public license
  observation after upload. Product license remains LGPL-3.0-only; dependencies
  retain their own notices and licenses.
- Container publication, cosign signature, provenance and SBOM passed the release event.
  Snap stable revision 10 and its LGPL-3.0-only product metadata are publicly verified.
  Real SuperCloud end-to-end acceptance and clean-device checks remain separate;
  unit tests and a signed build do not prove them.

## Remaining limits

This is still public test software with tracked findings in `knownbugs.md`.
Production account registration (#42), full SuperCloud deployment acceptance
(#73), real-device installation checks and any Store/package permissions require
their actual environments. They are not silently marked complete by this release.
