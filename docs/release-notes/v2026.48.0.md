# Open Calc Studio 2026.48.0

24 November 2026. Product version **2026.48.0**, Windows MSI **26.48.0**.
The native project format stays **2.4.0**.

## Price libraries — #93, #104, #84

- Choose the country library per estimate. A country without a bundled library
  shows that explicitly; it does not silently use Dutch articles or prices.
- Import your own JSON, CSV/Excel or BMEcat library, retain several libraries
  side by side, and switch each on or off for an estimate. Rename, replace and
  remove libraries without clearing the prices already entered in estimates.
- CSV/Excel imports now show a preview and editable column mapping, including
  code, description, unit, price, resource type, category, source, reference
  date, currency and VAT basis. Successful mappings are remembered for files
  with the same headers. Cancelling does not import a library.
- Libraries persist in desktop app data or web IndexedDB. Stable catalogue and
  article IDs preserve price links on re-import. Missing libraries are reported.
- MCP `app_command` and the hosted `calc_run_action` expose `libraries.list`,
  `libraries.import`, `libraries.select`, `libraries.rename`, `libraries.remove`.
  Replacing an existing library requires `replace: true`; importing does not
  change estimate prices or automatically activate the library.
- Missing prices remain missing. Library country and currency choices do not
  convert amounts or establish local market prices. VAT basis is retained as
  source metadata; it does not convert an inclusive price to an exclusive one.

Format guide and examples: [price-library-format.md](../price-library-format.md).
The worldwide cost-source research continues separately; this release does not
claim verified price coverage for every country.

## Measurement lines, codes and grid — #95–#98

- Edit itemised measurement lines under a budget item, with dimensions and
  formula-derived quantity. Read and write the lines in BC3. Link replacement
  asks before discarding an existing measurement breakdown.
- Show the estimate's own item codes, retain them in supported reports, keep
  the unit column next to the count, and fully hide disabled columns.
- Grid context menus stay within the window.

## Import and calculation — #83, #88

- Review stored Excel formula results before import. Missing formula results
  and error cells are identified rather than silently used as quantities.
  MCP Excel import follows the same importer as the app.
- Per-estimate FIEBDC rounding and BC3 indirect costs improve agreement with
  source totals. Percentage markups continue to follow edited item amounts.
  Imported totals can therefore differ from earlier app versions; compare with
  the original budget before approving an estimate.

## PDF workspace and reports — #99, #101, #103

- Compact PDF toolbar, fit-to-width and clearer calibration/measurement hints.
  Linked PDF measurements also set the matching length or area unit.
- Built-in report fonts restore text in reports on macOS and Linux. Typst
  reports use currency-symbol and Arabic fallback fonts.
- Draft PR #105 is **not included**: its additional layout-report fallbacks
  depend on openaec-reports PR #24. Some scripts/currency signs in those
  reports still have the limitations listed in `knownbugs.md`.
