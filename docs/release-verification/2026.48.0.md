## UI acceptance performed

The deployed public web app showed 2026.48.0. A separate temporary estimate
was used to import two synthetic CSV articles with custom headers. Manual
column mapping worked, the absent price stayed empty, individual library
selection worked, and re-import remembered the mapping. Cancelling re-import
did not change the library. [Screenshot and capture details](../screenshots/2026.48.0/README.md).

This is not a claim of clean-machine installer acceptance on every OS or
physical Android/iPhone testing. Draft #105 is excluded; the private Presto
workbook in #94 has not been accepted.

## Snap Store: explicit remaining blocker

The Snap build and its GitHub archive upload succeeded. Store publication
failed because the exported Store credentials expired:
[run 45403194253](https://github.com/OpenAEC-Foundation/open-calc-studio/actions/runs/45403194253),
[credential recovery #109](https://github.com/OpenAEC-Foundation/open-calc-studio/issues/109).

The public Store API still reported **2026.46.1, revision 11**, with
**LGPL-3.0-only**, on 24 November. Do not describe the Store as updated to
2026.48.0. Renew the scoped credential and publish the existing archive's exact
bytes. Avoid rerunning a path that overwrites already published assets.

`SHA256SUMS.txt` covers the initial release artifacts. The subsequently added
Snap archive and updater each have their own checksum file.
