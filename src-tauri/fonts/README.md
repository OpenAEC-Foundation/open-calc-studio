# Report fonts

Noto Sans Arabic, Regular and Bold, version 2.013. The PDF reports made with
Typst (Bouw 1, IBIS-stijl, directiebegroting) use it as a fallback for Arabic,
Persian and Urdu text, which Liberation Sans lacks. See
`src-tauri/src/reports/fonts.rs`.
